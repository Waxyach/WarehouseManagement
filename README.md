# WarehouseManagementApp — АІС складського обліку

Настільний застосунок для Windows, призначений для ведення складського обліку, контролю товарних залишків у реальному часі, оформлення складських накладних та формування аналітичної звітності.

Програма працює повністю автономно з локальною реляційною базою даних SQLite і не потребує розгортання окремих серверів чи постійного підключення до мережі.

---

## Основні можливості

- **Облік номенклатури:** створення, редагування та видалення карток товарів з автоматичною генерацією унікального артикулу, контролем закупівельних і роздрібних цін та налаштуванням мінімального порогу залишку.
- **Два режими перегляду каталогу:**
  - *Табличний режим* із швидким пошуком за назвою чи артикулом, фільтрацією за категоріями та окремим фільтром дефіцитних позицій;
  - *Ієрархічний режим* із групуванням товарів за категоріями у вигляді розкривних блоків.
- **Контроль дефіциту:** автоматичне виділення рядків товарів, фактичний залишок яких досяг або опустився нижче встановленого нормативу.
- **Документообіг:** оформлення та проведення прибуткових накладних (`REC`), видаткових накладних (`EXP`) та актів списання (`WRO`) з автоматичною генерацією номерів за датою.
- **Захист цілісності даних:**
  - блокування списання або продажу кількості товару, що перевищує фактичний залишок на складі;
  - контроль цілочисельності (заборона дробових значень для неподільних одиниць виміру);
  - атомарне проведення документів у межах єдиної транзакції БД (відкат змін у разі помилки);
  - захист від видалення товарів, категорій та одиниць виміру, що вже задіяні в обліку.
- **Довідники:** керування категоріями товарів із вибором індивідуального колірного маркера через палітру та класифікатором одиниць виміру (цілочисельні / дробові) з автоматичною ініціалізацією базового набору при першому запуску.
- **Аналітична звітність:** експорт поточної відомості залишків із розрахунковими формулами сум і виділенням дефіциту у формат Microsoft Excel (`.xlsx`).

## Технологічний стек

- **Платформа та мова:** C# / .NET 9
- **Графічний інтерфейс:** Windows Presentation Foundation (WPF) + [WPF-UI](https://github.com/lepoco/wpfui) (стилізація під Windows 11 Fluent Design)
- **Архітектура:** MVVM ([CommunityToolkit.Mvvm](https://learn.microsoft.com/en-us/dotnet/communitytoolkit/mvvm/)) + Dependency Injection (`Microsoft.Extensions.DependencyInjection`)
- **База даних та ORM:** SQLite + Entity Framework Core (`Microsoft.EntityFrameworkCore.Sqlite`)
- **Генерація звітів:** [ClosedXML](https://github.com/ClosedXML/ClosedXML)

## Структура проєкту

```text
WarehouseManagementApp/
├── Common/          # Спільні допоміжні класи та константи
├── Converters/      # Конвертери значень XAML (IValueConverter)
├── Data/            # Контекст бази даних, початкове заповнення БД
├── Helpers/         # Утиліти парсингу числових значень та валідації вводу
├── Models/          # Доменні сутності та переліки
├── Resources/       # Словники ресурсів XAML, стилі елементів керування та колірні палітри
├── Services/        # Інтерфейси та реалізації бізнес-логіки
├── ViewModels/      # Моделі представлення з командами та властивостями
├── Views/           # Вікна та діалогові форми інтерфейсу користувача
└── App.xaml.cs      # Точка входу

```

## Встановлення та запуск

### Варіант 1. Запуск готової збірки (для користувачів)

1. Перейдіть на вкладку [Releases](https://github.com/Waxyach/WarehouseManagement/releases/latest).
2. Завантажте архів з останньою актуальною версією програми.
3. Розпакуйте вміст архіву у будь-яку папку.
4. Запустіть файл `WarehouseManagementApp.exe`.

### Варіант 2. Збірка з вихідного коду (для розробників)

1. Клонуйте репозиторій:
```bash
git clone https://github.com/Waxyach/WarehouseManagement.git
cd WarehouseManagement

```


2. Відновіть залежності NuGet та зберіть проєкт через .NET CLI:
```bash
dotnet restore
dotnet build --configuration Release

```


3. Запустіть застосунок:
```bash
dotnet run --project WarehouseManagementApp

```


Або відкрийте файл рішення `.sln` у **Visual Studio 2022** та натисніть `F5`.
